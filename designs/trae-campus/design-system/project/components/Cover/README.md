# Cover

全屏封面：一句主张 + 一行副标题 + 演讲者名签，用于开场与分场封面。

## 用途

每次分享只有一张封面。它承担三件事：说清主题（主张）、给出视角（副标题）、介绍讲者（名签）。不写议程、不写时间地点、不放二维码。

## 结构（自上而下）

1. **画布**：1920×1080，`background: surface`；左右留白 115px，内容在垂直方向居中。
2. **字标位**：left 115 / top 64，尺寸 138×46。本系统**不随附 TRAE logo**，预览里用 `24px / 600 / 2.4px` 的纯文字 `TRAE CAMPUS` 占位。
3. **主张**：`display` 档 104px / 1.22 / 800 / 字距 -3px，正文左缩进 360px；关键词用 `accent-text`。
4. **副标题**：41px / 1.2 / 400 / `text-body-soft`，`padding-top: 31px`、`padding-left: 86px`，以「— 」开头。
5. **名签**：薄荷胶囊 `334×83`，`radius-pill`、`background: surface-mint`、内边距 `17px 48px`，名字 41px / 1.2 / 800 / `text-heading`；名签上方预留 190×167 的讲者照片位（照片不随系统分发，预览里保持留白）。

## 规则

- 一页只出现一次 `display` 104px；封面不设眉标、不设页头分隔线。
- 关键词只用 `accent-text`（#17754A）；`accent-brand`（#2FAE72）只用于圆点、边框与图形，不当文字。
- 副标题只有一行，不加句号以外的标点；不堆第二句。
- 名签文字固定 41px / 800，不加职位、不加公司后缀——职位信息留在 About Me。
- 右侧大面积留白是有意的：原版的小助手插画是场次专属资产，不随系统分发，替换时保持 780×520、`bottom: 67px`、`right: 0`。

## 不随本系统分发

TRAE logo、TRAE 小助手插画、讲者头像/照片只属于该场分享，不可从本设计系统复制。需要时向 TRAE 官方获取素材，并保持上表的位置与尺寸。

## 消费者提供

讲稿标题与副标题、讲者名、logo（官方素材）、讲者照片、插画（官方素材）。没有素材时只放纯文字，不自行绘制。

## 预览

`preview.html` 是一张 1920×1080 画布，外层 480×270 + `overflow:hidden`，内部 `transform:scale(0.25)`，因此在 460px 高的卡片里完整显示整页版式；只引用 `../../tokens.css`，静态、无脚本、无外部资源。
